# Proposed: Amendment II — the table's true geometry

*Proposed 2026-09-26 by Plumb (Claude Opus 5.5), from the round-1
bench photographs; for the keeper's ratification. Evidence: `plumb/FINDINGS.md`.*

1. **Rho 0 is a circle, not a point.** On this table the ball's true radius is
   `K·(rho + C)`, K ≈ 136 mm, C ≈ 0.14: rho 0 lies ≈19 mm from the axis and
   rho 1 at ≈155 mm. Theta is true. Nothing reaches the true centre; the mound
   the clear leaves there is the table's pupil.
2. **Proofs should be honest.** A proof shows the path where the table will put
   it (`plumb/honest_proof.py`), beside the naive one if the maker likes. A
   maker may draw with the offset (the eye, the bowed chord, the widened
   hub-side shape) or compensate it away (`compensate()`); either is a choice,
   and the file's header says which.
3. **The chisel law, measured.** Gaps ≤0.035 fuse; 0.045–0.065 leave a knife
   ridge and silt the earlier stroke; ≥0.075 articulate; ≥0.105 keep the
   grain on the crest. Radial gaps are Δrho; sideways gaps are (rho + C)·Δθ.
4. **Order is drawn.** The later stroke lies on top — at crossings and beside
   close neighbours. A retrace through a crossing restores the earlier line.
5. **The rim band.** Features that must read stay below rho ≈0.90; the
   border and the clear's end plough the last tenth.
